Твої програми на новому ПК одним кліком

Перевстановлення Windows без болю

Жодних вечорів у стилі «як там звалася та програма?» і завантаження установників по одному.

01

Додай свої програми

Встав посилання на GitHub, GitLab, Codeberg чи сторінку завантаження, вибери з ~70 програм «Добірки» або забери все встановлене з цього ПК через winget.

02

Познач «Мій набір»

Програми, посилання й твіки, без яких ніяк. Набір синхронізується через секретний GitHub Gist або їде одним zip.

03

Встанови набір

На новому чи щойно перевстановленому ПК відкрий Komora й натисни «Встановити набір». Програми, їхні налаштування й твої твіки повертаються.

А поки вона сидить у треї

Усе інше, чого потребує свіжа Windows, — в одній маленькій програмі.

Оновлення самі

Нові версії з GitHub, GitLab, Codeberg і winget, з перевіркою підпису й контрольної суми перед встановленням.

Твіки Windows

Перемикачі з кнопкою «скасувати» й попередження, коли оновлення Windows тихо їх скидає.

Виправлення одним кліком

Кеш шейдерів, тимчасові файли, DNS, завислі оновлення Windows, кеш Store, sfc і DISM.

Цей ПК

Процесор, відеокарта, пам’ять, плата й диски — з посиланнями на драйвери й BIOS виробників.

Безпечно з коробки

Підпис Authenticode, SHA-256 проти релізу й за бажання перевірка кожного файлу на VirusTotal.

Бібліотека, а не список

Групи, теги й нотатки, копії налаштувань перед кожним оновленням, відкат портативних програм.

Ближче

Темна чи світла, шість тл, власна шапка вікна.

Нехай наступне перевстановлення буде нудним

Безкоштовно, без облікового запису й реклами. Один exe для Windows 10 і 11.
